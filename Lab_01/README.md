# Лабораторна робота №1

## Варіант 8 — Аналіз банківських транзакцій

### Опис проєкту

Програма призначена для обробки та аналізу банківських транзакцій із використанням принципів функціонального програмування у Python.

Програма відбирає успішні транзакції, перевіряє мінімальну суму, конвертує валюту в гривні та застосовує комісію.

### Реалізований функціонал

- Відбір транзакцій зі статусом `successful`.
- Перевірка мінімальної суми транзакції.
- Конвертація валют за заданим курсом.
- Застосування комісії.
- Обчислення загальної суми оброблених транзакцій.
- Підрахунок кількості оброблених транзакцій.

### Використані принципи функціонального програмування

- **Чисті функції** — однакові вхідні дані забезпечують однаковий результат без зміни зовнішнього стану.
- **Референтна прозорість** — результат функції залежить лише від її аргументів.
- **Відсутність мутації** — початкові дані транзакцій не змінюються, натомість створюються нові об'єкти.
- **Ізоляція побічних ефектів** — введення та виведення даних винесено в `app.py`.
- **Callable** — функції курсу валют, комісії та фільтрації передаються як аргументи.
