# Лабораторна робота №1

## Варіант 15 — Спортивні результати

### Опис проєкту

Програма призначена для обробки та аналізу спортивних результатів із використанням принципів функціонального програмування у Python.

Програма відбирає спортсменів зі статусом `completed`, обчислює середній результат їхніх спроб, нараховує бонуси та штрафи, визначає підсумковий результат і перевіряє кваліфікацію відповідно до категорії спортсмена.

### Реалізований функціонал

- Відбір спортсменів зі статусом `completed`.
- Обчислення середнього результату спортивних спроб.
- Нарахування бонусів залежно від категорії спортсмена.
- Обчислення штрафів залежно від кількості спроб.
- Розрахунок підсумкового результату з урахуванням бонусу та штрафу.
- Перевірка кваліфікації спортсмена.
- Підрахунок кількості оброблених, кваліфікованих і некваліфікованих спортсменів.

### Використані принципи функціонального програмування

- **Чисті функції** — однакові вхідні дані забезпечують однаковий результат без зміни зовнішнього стану.
- **Референтна прозорість** — результат функції залежить лише від її аргументів.
- **Відсутність мутації** — початкові дані спортсменів не змінюються, натомість створюються нові об'єкти з обробленими результатами.
- **Ізоляція побічних ефектів** — виведення результатів винесено в `app.py`.
- **Callable** — функції агрегації, нарахування бонусу, обчислення штрафу та перевірки кваліфікації передаються як аргументи.
- **Функції вищого порядку** — використовується `make_processor()`, яка повертає налаштований обробник спортивних результатів.
