# Лабораторна робота 6 — варіант 15

## Тема
Композиція декораторів для сервісної функції.

## Завдання
Показати композицію `@cached`, `@retries`, `@timed` та closure-логера. Порівняти порядок застосування декораторів і вплив кеш-хітів на кількість звернень до сервісної функції.

## Реалізація
- `closures.py`: `make_logger()` та `make_counter()`; лічильник зберігає змінний стан через `nonlocal`.
- `decorators.py`: параметризовані `timed`, `retries`, `cached`, усі з `functools.wraps`, `ParamSpec` і `TypeVar`.
- `app.py`: сервісна функція з двома порядками композиції.
- `tests/`: перевірки замикань, метаданих, таймінгу, повторів, TTL, інвалідації та композиції.

## Порядок декораторів
У Python декоратори застосовуються знизу вгору. У `cache_outer` кеш обгортає вимірювання та повтори: повторний запит із тим самим ключем завершується кеш-хітом і не запускає внутрішні шари. У `retry_outer` повтори обгортають кеш: помилки не кешуються, а успішний результат зберігається та використовується під час наступного запиту.

## Запуск (Windows)
```powershell
python -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
pytest -q
python app.py
```

## Перевірка якості
```powershell
mypy .
black --check .
ruff check .
```

У тестах `sleep`, `clock`, `logger` і `time_fn` ін'єктуються, тому не використовуються реальні затримки та нестабільні часові вимірювання.
